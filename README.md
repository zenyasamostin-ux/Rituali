# Ritualia

Приложение с денежными ритуалами для iOS, Android и веба. Рабочее название, не утверждено.

## Запуск

```bash
npm install
npm start          # Expo dev server: i — iOS, a — Android, w — веб
npm test           # тесты движка расписания, астрономии и переводов
npm run typecheck
npm run lint
```

Напоминания работают только на телефоне, в вебе их нет. Для проверки на телефоне хватит Expo Go.

### APK для Android

GitHub Actions собирает APK при каждом PR и пуше в main (`.github/workflows/android-apk.yml`). Скачать его можно на вкладке Actions: откройте запуск «Android APK» и внизу, в разделе Artifacts, нажмите `ritualia-apk`. Внутри zip-архива лежит `app-release.apk`. Сборку можно запустить и вручную кнопкой Run workflow.

APK подписан отладочным ключом. Он годится для тестов, но не для Google Play.

## Как устроено

```
src/
  app/                 экраны (expo-router): каждый файл — маршрут
    _layout.tsx        корневой стек и провайдеры
    index.tsx          главная: ритуалы на сегодня, календарь с выбором напоминаний, история
    ritual/[id].tsx    карточка ритуала: описание, что нужно, действие, наговор, отметка
    settings.tsx       язык, тестовая подписка, напоминания по ритуалам
  rituals/             модель ритуала и каталог (29 ритуалов, включая 7 симоронских, правила расписания)
  content/rituals/     тексты ритуалов по языкам (ru — источник, en — перевод)
  schedule/            движок: какие ритуалы в какой день, серия дней, история
  astro/               фазы луны, равноденствия, Масленица, китайский Новый год
  notifications/       план напоминаний и планирование через expo-notifications
  i18n/                i18next и строки интерфейса на шесть языков
  state/               профиль и отметки, сохраняются в AsyncStorage
```

### Каталог и расписание

Каждый ритуал в `src/rituals/catalog.ts` — это id, бесплатный или платный, эмодзи, время по умолчанию и правило дня:

- `weekly` — каждую неделю в один и тот же день.
- `monthDay` — каждый месяц в одно и то же число.
- `moon`, `season` — фазы луны и равноденствия считаются по формулам Миуса («Astronomical Algorithms»), без сети. Точность — минуты, тесты сверяют с реальными датами.
- `fixedDate`, `mirrorDate`, `movable` — праздники и зеркальные даты.

Тексты лежат отдельно от правил, поэтому перевод не трогает логику.

### Напоминания

При запуске, возврате в приложение и любом изменении настроек план пересобирается на 30 дней вперёд, не больше 60 уведомлений (у iOS лимит 64). Ритуалы и отдельные дни, у которых напоминание выключено в календаре или настройках, пропускаются. Платный ритуал без подписки превращается в анонс «Скоро особый ритуал» накануне в 19:00. Нажатие на уведомление открывает карточку ритуала.
