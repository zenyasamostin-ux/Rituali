# Ritualia

Приложение с денежными ритуалами для iOS, Android и веба. Рабочее название, не утверждено.

## Запуск

```bash
npm install
npm start          # Expo dev server: i — iOS, a — Android, w — веб
npm test           # тесты движка расписания, астрономии и переводов
npm run typecheck
npm run lint
```

Напоминания работают только на телефоне, в вебе их нет. Для проверки на телефоне хватит Expo Go.

### APK для Android

GitHub Actions собирает APK при каждом PR и пуше в main (`.github/workflows/android-apk.yml`). Скачать его можно на вкладке Actions: откройте запуск «Android APK» и внизу, в разделе Artifacts, нажмите `ritualia-apk`. Внутри zip-архива лежит `app-release.apk`. Сборку можно запустить и вручную кнопкой Run workflow.

APK подписан отладочным ключом. Он годится для тестов, но не для Google Play.

## Как устроено

```
src/
  app/                 экраны (expo-router): каждый файл — маршрут
    _layout.tsx        корневой стек и провайдеры
    index.tsx          «Сегодня» и ближайшая неделя
    ritual/[id].tsx    карточка ритуала: что нужно, действие, приговор, отметка
    settings.tsx       язык, ритм, напоминания, даты зарплаты, счетов, дня рождения
  rituals/             модель ритуала и каталог (33 ритуала, правила расписания)
  content/rituals/     тексты ритуалов по языкам (ru — источник, en — перевод)
  schedule/            движок: какие ритуалы в какой день, серия дней
  astro/               фазы луны, затмения, равноденствия, Масленица, китайский Новый год
  notifications/       план напоминаний и планирование через expo-notifications
  i18n/                i18next и строки интерфейса на шесть языков
  state/               профиль и отметки, сохраняются в AsyncStorage
```

### Каталог и расписание

Каждый ритуал в `src/rituals/catalog.ts` — это id, бесплатный или платный, эмодзи, время по умолчанию и правило дня:

- `cycle` — недели А и Б чередуются, считаются от понедельника недели, в которую пользователь начал. В ритме «через день» берутся только чётные дни 14-дневного цикла.
- `monthDay`, `lastDayOfMonth`, `profileDay` — ежемесячные. День зарплаты 31 в коротком месяце становится последним днём.
- `moon`, `season`, `eclipse` — считаются по формулам Миуса («Astronomical Algorithms»), без сети. Точность — минуты, тесты сверяют с реальными датами 2024–2026.
- `fixedDate`, `mirrorDate`, `movable`, `birthday` — праздники и личные даты.

Тексты лежат отдельно от правил, поэтому перевод не трогает логику.

### Напоминания

При запуске, возврате в приложение и любом изменении настроек план пересобирается на 30 дней вперёд, не больше 60 уведомлений (у iOS лимит 64). Платный ритуал без подписки превращается в анонс «Скоро особый ритуал» накануне в 19:00. Нажатие на уведомление открывает карточку ритуала.
